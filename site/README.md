# Cognitive Memory Documentation Site

This directory contains the Astro-based static site for the Cognitive Memory project.

## Technology Stack

- **[Astro](https://astro.build/)** - Static site generator
- **[Tailwind CSS v4](https://tailwindcss.com/)** - Utility-first CSS framework
- **[Scalar](https://scalar.com/)** - OpenAPI reference renderer
- **[MDX](https://mdxjs.com/)** - Markdown with JSX support for docs

## Local Development

### Prerequisites

- Node.js 20+ 
- npm

### Getting Started

```bash
# Install dependencies
npm install

# Start development server (http://localhost:4321)
npm run dev

# Build the site
npm run build

# Preview the built site
npm run preview
```

The OpenAPI spec (`public/openapi.json`) is generated by the Quarkus build. To regenerate it:

```bash
cd ../cognition-processor-quarkus
./mvnw compile quarkus:build -DskipTests
```

## Project Structure

```
site/
├── public/              # Static assets (favicon, openapi.json, openapi.yaml)
├── src/
│   ├── components/      # Astro components (Header, Footer, Sidebar, etc.)
│   ├── layouts/         # Page layouts (BaseLayout, DocsLayout)
│   ├── pages/           # File-based routing
│   │   ├── index.astro  # Home page
│   │   └── docs/        # Documentation pages
│   │       ├── index.md # Overview
│   │       └── api/     # API reference (Scalar)
│   └── styles/          # Global CSS (Tailwind)
├── astro.config.mjs     # Astro configuration
├── package.json
└── tsconfig.json
```

## Configuration

### Environment Variables

| Variable | Description | Default |
|----------|-------------|---------|
| `ASTRO_BASE` | Base path for the site | `/` |
| `ASTRO_SITE` | Full site URL | `https://rigazilla.github.io` |

### Building for GitHub Pages

```bash
ASTRO_BASE=/cognitive-memory/ npm run build
```

## Deployment

Deployment is handled automatically by `.github/workflows/deploy-site.yml` on push to `main`.

### GitHub Pages Setup

1. Go to repository Settings > Pages
2. Set Source to **GitHub Actions**
3. The workflow deploys automatically on push to `main`

The site is published at: https://rigazilla.github.io/cognitive-memory/

### OpenAPI Sync Check

The `.github/workflows/verify-openapi.yml` workflow runs on PRs to ensure the checked-in OpenAPI spec matches what the Quarkus build generates. If it fails, regenerate the spec:

```bash
cd cognition-processor-quarkus
./mvnw compile quarkus:build -DskipTests
```

Then commit the updated `site/public/openapi.json` and `site/public/openapi.yaml`.
